# Parth Rastogi — Law Portfolio

Static site (HTML/CSS/vanilla JS, no build step) for Parth Rastogi, U.S. civil litigation paralegal.

- `index.html` — landing page
- `publications.html` — all publications
- `publications-data.js` — add a publication here and it appears on both pages
- `style.css`, `script.js`
- `Parth_Rastogi_Resume.pdf`

Deploy: any static host (Render Static Site: build command empty, publish directory `.`).
Photography: Unsplash.
